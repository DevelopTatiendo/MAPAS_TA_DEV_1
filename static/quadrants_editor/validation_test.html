🎯 Flujo de Uso Completo

📝 Creación Nueva (T1-T5):

  1. Crear cuadrante padre: Clic en "➕ Crear cuadrante (padre)" → Dibujar polígono → Configurar ciudad, ruta, código
  2. Crear subcuadrantes: Clic en "➕ Crear subcuadrantes (hijos)" → Dibujar polígonos hijos dentro del padre
  3. Autocompletar: Clic en "🔄 Autocompletar restante" para llenar áreas no cubiertas
  4. Validación: Al exportar, el sistema valida integridad (100% cobertura, 0 solapes, dentro del padre)
  5. Exportar (T6): GeoJSON con nombre "subcuadrante_CL_{ruta}_{nn}.geojson" y propiedades completas

📂 Continuar Edición (T7):

  1. Importar archivo: Clic en "Importar GeoJSON" → Seleccionar archivo con jerarquía
  2. Seleccionar cuadrante: El sistema detecta la jerarquía y muestra selector agrupado por ruta
  3. Cargar jerarquía: Seleccionar cuadrante padre → Se cargan automáticamente todos sus subcuadrantes
  4. Editar: Continuar editando padre e hijos con todas las funcionalidades disponibles
  5. Re-exportar: Mantener o actualizar la jerarquía con nuevas modificaciones

⚙️ Configuración Técnica (T7):

  • CRS Métrico: EPSG:3116 (Colombia) para cálculos precisos
  • Tolerancias: Snapping 1.0m, Área mín. 0.01m², Validación 0.5m
  • Sanitización: Buffer(0) aplicado automáticamente
  • Indexación: Padres e hijos organizados por código_padre
